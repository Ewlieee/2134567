# Техническая архитектура
## Веб-приложение — «Книжная полка»

Документ описывает техническую реализацию проекта. Архитектура является классической клиент-серверной и опирается на стек, зафиксированный в исходных данных.

## 1. Зафиксированные ограничения
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS или React).
- **Backend:** Node.js (среда выполнения JavaScript), Express.js.
- **СУБД:** Microsoft SQL Server.
- **Среда разработки:** Visual Studio Code, ОС Windows 10.
- **Драйвер БД:** `mssql` (пакет npm для Node.js).
- Все данные хранятся в реляционной базе данных MS SQL Server.
- Книги не хранятся в виде файлов на сервере, приложение агрегирует метаданные.

## 2. Общая архитектура

```text
Браузер (HTML/CSS/JS)
          |
        HTTP/HTTPS (REST API / AJAX)
          |
          v
      Node.js (Express.js)
          |
          +-- Маршрутизация (Routes)
          +-- Контроллеры (Controllers)
          +-- Модели (Models) <---> MS SQL Server (mssql)
          |
          +-- Файловая система (uploads/ для обложек)
