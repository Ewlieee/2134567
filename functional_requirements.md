# Функциональные требования
## Веб-приложение — «Книжная полка»

## 1. Общая концепция
Веб-приложение предназначено для каталогизации книг, ведения личной читательской полки, отслеживания прогресса чтения и обмена отзывами. 
Приложение не продает книги, а служит инструментом для организации чтения и ведения читательского дневника. Покупка или скачивание книг происходит на сторонних ресурсах.

## 2. Роли пользователей

### 2.1. Гость
Неавторизованный посетитель приложения.
Возможности:
- Просматривать главную страницу и каталог книг.
- Искать книги по названию и автору.
- Фильтровать и сортировать каталог.
- Просматривать страницы книг, авторов и жанров.
- Читать отзывы и рейтинги.
- Регистрироваться и авторизовываться.

### 2.2. Зарегистрированный пользователь (Читатель)
Возможности:
- Использовать все функции гостя.
- Просматривать и редактировать свой профиль.
- Добавлять книги на личную полку (статусы: «Хочу прочитать», «Читаю», «Прочитано»).
- Отслеживать прогресс чтения (текущая страница, процент завершения).
- Оставлять отзывы и ставить оценки книгам.
- Подавать заявки на добавление новых книг в каталог.
- Просматривать статус своих заявок.

### 2.3. Администратор
Возможности:
- Просматривать сводную статистику приложения.
- Создавать, редактировать и архивировать книги.
- Управлять авторами, жанрами.
- Модерировать заявки пользователей на добавление книг.
- Модерировать отзывы (удалять спам).
- Управлять пользователями (блокировка/разблокировка).
- Публиковать новости и объявления.

## 3. Главная страница
Функциональность:
- Отображение строки поиска.
- Отображение популярных жанров.
- Отображение топ-10 книг по рейтингу.
- Отображение новинок каталога.
- Отображение последних новостей.
- Переход к полному каталогу.

## 4. Каталог книг
### 4.1. Поиск
Поиск по названию книги, автору, ISBN.

### 4.2. Фильтрация
- По жанру.
- По автору.
- По году издания.
- По языку.
- По количеству страниц (диапазон).

### 4.3. Сортировка
- По рейтингу.
- По дате добавления.
- По названию (А-Я).
- По году издания.

### 4.4. Карточка книги в каталоге
- Обложка, название, автор, жанр, год издания.
- Средний рейтинг.
- Кнопка «Добавить на полку» (для авторизованных).

## 5. Страница книги
- Обложка, название, автор, жанр.
- Аннотация.
- ISBN, издательство, язык, количество страниц.
- Список отзывов и оценок.
- Форма добавления отзыва (для авторизованных).
- Кнопки управления статусом на полке.
- Поле для ввода текущей страницы (если статус «Читаю»).

## 6. Личная книжная полка
- Отображение всех книг пользователя с разделением по статусам.
- Возможность менять статус книги.
- Визуализация прогресса чтения (прогресс-бар).
- Возможность удалить книгу с полки.

## 7. Заявки на добавление книг
- Пользователь заполняет форму (название, автор, комментарий).
- Заявка попадает в админ-панель.
- Администратор одобряет (книга добавляется) или отклоняет.
- Пользователь видит статус заявки.

## 8. Отзывы и оценки
- Один отзыв на книгу от пользователя.
- Оценка от 1 до 5 звезд.
- Текстовый комментарий.
- Возможность редактировать и удалять свой отзыв.

## 9. Панель администратора
### 9.1. Дашборд
- Количество книг, пользователей, отзывов.
- Количество активных заявок.
- График добавления книг по месяцам.

### 9.2. Управление книгами
- Создание, редактирование, удаление.
- Привязка к авторам и жанрам.

### 9.3. Модерация
- Заявки пользователей.
- Отзывы.

### 9.4. Управление пользователями
- Просмотр списка, блокировка/разблокировка.

## 10. Основные правила работы приложения
- Одна книга принадлежит одному автору и одному жанру.
- Один пользователь оставляет только один отзыв на книгу.
- Добавление на полку доступно только авторизованным.
- Пароли хранятся в хешированном виде.

## 11. Приоритеты реализации
### Первая версия (MVP)
- Регистрация и авторизация.
- Каталог, поиск и фильтрация.
- Страница книги.
- Личная полка с прогрессом чтения.
- Отзывы и оценки.
- Панель администратора (CRUD книг).
- Заявки на добавление книг.

### Расширенная версия
- Персональные рекомендации.
- Расширенная статистика.
- Публикация новостей.
- Внутренние сообщения.
